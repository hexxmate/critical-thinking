# Link Index

Every URL mentioned in the *Critical Thinking - Bug Bounty Podcast* show notes and transcripts —
**1,255 unique links**, split by category and deduplicated.

The links were extracted from the official episode descriptions (all 199 episodes) and normalized:
tracking parameters and fragments were removed, `twitter.com` profiles were folded into `x.com`,
and obvious podcast-platform boilerplate was excluded.

## How to use

- **Build a follow list** — start with [`x-profiles.md`](x-profiles.md).
- **Find a report to read** — open [`hackerone-reports.md`](hackerone-reports.md).
- **Find a tool or repo** — open [`github.md`](github.md).
- **Go down a research rabbit hole** — [`blogs-and-websites.md`](blogs-and-websites.md) is the
  long tail of everything else.

## Caveats

- Links belong to their respective authors. Inclusion is not an endorsement.
- Some links have moved, expired, or been taken down since the episode aired.
- A small number of links are shorteners whose destination is not visible in the URL.
- The lists are generated artifacts. To add or fix a link, edit the relevant Markdown file and
  mention it in a pull request.

See [`../NOTICE.md`](../NOTICE.md) for attribution and [`../CONTRIBUTING.md`](../CONTRIBUTING.md)
for contribution guidelines.
