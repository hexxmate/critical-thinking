# Episode Summary Template

Use this template for every file in [`notes/`](../notes/). Keep it to roughly one page. Delete
sections that do not apply rather than filling them with filler.

```markdown
---
episode: 123
title: "Episode title"
tags: [tag-one, tag-two]
primary_tag: tag-one
source: "https://www.criticalthinkingpodcast.io/..."
transcript: "../transcripts/123-title.txt"
---

# Episode 123 — Title

**Guests:** Name, Name
**Hosts:** Rhynorater, rez0, gr3pme
**One-line summary:** What this episode is actually about.

## TL;DR

Three to five bullets capturing the most useful takeaways.

## Key techniques

- **Technique name** — what it is, when it works, and any prerequisites or limits.
- **Technique name** — same.

## Tools & resources

- Tool or resource — what it is used for, with a link if one exists.
- Tool or resource — same.

## Notable claims & lessons

- A specific claim, number, or lesson from the episode.
- Another one. Keep attribution: "According to <guest>…" when relevant.

## Agent & automation ideas

Concrete ideas inspired by the episode. Each idea should be actionable.

- **Idea:** a skill, automation, checklist, or agent capability.
  - **Why:** the problem it solves.
  - **Evidence:** the episode segment or technique it comes from.
  - **Effort:** small / medium / large.

## Follow-ups

- Links to read, repositories to inspect, or reports to study.
- Open questions the episode raised.

## Related episodes

- Episode NNN — why it is related.
```

## Notes

- Frontmatter `tags` must use the vocabulary in [`TAXONOMY.md`](TAXONOMY.md).
- Keep quotes short. Paraphrase unless the exact wording matters.
- If an idea is speculative, label it as such. Do not present it as something the hosts said.
- Link to the transcript so readers can verify details.
